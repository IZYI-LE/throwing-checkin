# 投掷组训练打卡 · 网页版

纯前端单文件应用，数据保存在浏览器 localStorage。

## 使用

打开 GitHub Pages 链接即可使用。首次使用：

- 管理员：创建管理员成员并绑定当前设备
- 队员：在「我的」页导入管理员下发的成员名单 JSON，再回到首页点击自己的姓名绑定

## 功能

- 成员名单（搜索 / 今日状态）
- 每日打卡（来训练 / 请假带原因，当天可修改一次）
- 个人统计（总次数 / 本周 / 本月 / 请假）
- 全组统计（今日出勤 / 请假 / 未打卡 / 本周排行）
- 管理端（成员管理 / 记录管理 / 导出 CSV / 名单分发）

## 部署

仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` 即可。
